# 兼容性记录

当前正式版：**v1.5.0**，目标系统：Windows 7 SP1 x64。

## 已验证的当前路径

| 项目 | 证据范围 |
| --- | --- |
| 官方 Go 组件在 Win7 启动并接收平台任务 | 已通过前期虚拟机测试 |
| 完整下载与速度 | 已完成下载，测试反馈与官方速度相当；不代表所有网络和游戏的吞吐保证 |
| 暂停与恢复 | 测试反馈迅速响应 |
| 重启系统后续传 | 已通过测试 |
| 游戏校验与修复 | 已通过测试 |
| RC5 实体机安装与下载 | 已在 Win7 实体机修补并完成下载 |
| 正式包按需提权及最终组合 | 离线检查通过，尚未完成 Win7 实机回归 |
| 05 独立下载器 | 四个核心文件原样取自 v1.4.2 正式包，保留原功能和依赖 |

当前完整 Go 下载链验证集中在 FeverGames `1.18.45.8`。不能把旧前端的历史测试视为新 Go 核心与所有旧版本组合均已回归。

## 识别范围

| 组件 | 当前策略 |
| --- | --- |
| 前端精确配置 | 1.18.42.12-A、1.18.42.14-A/B、1.18.43.22-A、1.18.44.2-A、1.18.45.8-A/B |
| 未知前端 | Auto Profile v2：唯一候选、五点字节、可执行节、跳转目标及字符串引用验证 |
| Go A/B/C | 完整原版/修补后 SHA-256 识别 |
| Go 其他签名变体 | 仅接受归一化后已知程序主体哈希相同的文件 |
| Go 新编译构建 | 尚无通用结构适配；拒绝未知主体，需继续分析 |

同版本目录可能包含不同签名或不同前端布局，不能只凭目录名判断。程序主体相同的签名变体与真正重新编译的更新应分别处理。

## 系统和分发方式限制

- 32 位 Windows 不在当前支持范围内。
- Windows 8.1/10/11 不是本次实测结论的对象，请优先使用官方程序。
- 05 支持其现有 Manifest/Index/Chunk 下载链，不保证 Aria2/经典分发游戏可用。
- 能下载不等于游戏本体能在 Win7 上运行。
