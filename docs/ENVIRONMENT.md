# 系统环境要求

当前正式版：**v1.5.0**。目标系统为 **Windows 7 SP1 x64**；不提供 32 位系统支持。

## 平台补丁与独立下载器

| 功能 | 所需组件 |
| --- | --- |
| 01/02/03/04/06 平台补丁、检查、恢复及诊断 | CMD、Windows Script Host/cscript、MSXML3 或 6、ADODB.Stream、certutil 的 SHA-256 功能 |
| 自动提权 | 目标文件不可写时需要可用的 UAC/RunAs 和系统 cmd.exe |
| 05 独立下载器 | Windows PowerShell、.NET 2.0/3.5/4.x 中可用的 C# 编译器、包内 `app/libzstd.dll` |

平台补丁不再编译 C# 替代下载组件，因此无需 PowerShell、Python 或 .NET 编译器。05 仍沿用旧版实现，其依赖继续保留。两者都不要求安装 7-Zip 或单独准备 zstd.exe。

## 目录与权限

完整解压正式 ZIP，不要直接在压缩包视图中运行 CMD。建议放在当前用户可写目录；05 首次运行要在 `app` 目录编译核心。

01/06 会先识别并验证文件。需要写入时检查目标目录及 EXE 的可写条件，受限时才申请管理员权限。文件被占用也可能导致写入受限，请先退出客户端及下载进程。只读属性需先取消；提权不保证能解决占用或只读问题。

管理员权限是修改安装文件的条件，不是新增的 Go 核心运行依赖。

## 精简系统

缺少 WSH、MSXML、ADODB 或 certutil 会影响平台补丁。缺少 PowerShell/.NET 编译器只会影响 05。请提交完整错误和所用入口，避免将两条路径的依赖混为一谈。

## 网络与游戏

下载还受网络、CDN 和磁盘性能影响。短暂 0 B/s 不等于已定位为补丁故障；反馈时请注明阶段、持续时间和恢复情况。游戏本体对系统、驱动和运行库的要求需要另行判断。
