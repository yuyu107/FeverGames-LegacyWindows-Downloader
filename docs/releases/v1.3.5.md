# FeverGames Legacy Windows Downloader v1.3.5

## 主要变化

- 将 Zstandard 解压后端从外部 `7z.exe / zstd.exe` 改为进程内 `libzstd.dll`。
- Windows 7 用户不再需要另外安装 7-Zip。
- 使用 Zstandard 1.5.6 C API，通过 P/Invoke 调用 `ZSTD_decompressStream`。
- 正式版保留原有串行下载与文件重组逻辑；Test2 / Test3 / Test4 的实验并发参数不纳入正式版。
- 状态检查现在要求 FeverGames 版本目录中的 `libzstd.dll`。
- 诊断包新增 `decoder_info.txt`，记录 libzstd 版本和 SHA-256。
- 恢复官方文件时，仅在 SHA-256 与安装时记录一致的情况下删除工具复制的 `libzstd.dll`。
- 01 / 02 / 03 / 04 CMD 入口均加入“请先完整解压 ZIP”的检测。

## 已验证

- Windows 7 SP1 x64 + CLR 2.0：libzstd 1.5.6 P/Invoke 流式解压测试通过。
- 实际 FeverGames 下载已验证可以完全不使用 7-Zip。
- 继续支持已验证的前端布局：
  - 1.18.42.12-A
  - 1.18.42.14-A
  - 1.18.42.14-B
  - 1.18.43.22-A
