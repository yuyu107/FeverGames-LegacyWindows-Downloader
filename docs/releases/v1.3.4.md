# v1.3.4 - FeverGames 1.18.43.22 支持

v1.3.4 是当前建议使用的正式版本。

本版本新增 **FeverGames `1.18.43.22 / layout A`** 的精确字节支持，并保留 v1.3.2 / v1.3.3 已验证的 Windows 7 安装兼容修复。

## 一、FeverGames 1.18.43.22 / layout A

新版 `FeverGamesInstaller.exe` 的前端布局发生变化，旧版 profile 会安全拒绝安装。v1.3.4 重新定位并验证了 5 个目标位置：

```text
Gate A   = 0xA9C4A0
Gate B   = 0x6F564D
NetLabel = 0xA3FB5C
NetMinor = 0xA3FBD2
Getter   = 0xA41220
```

原版 `FeverGamesInstaller.exe` SHA-256：

```text
d86f38ea0ab650b94e467dfc7a3c0f01587fa90d6d079d9f04f5b87ae5579c27
```

## 二、Windows 7 实机验证

`1.18.43.22 / layout A` 已完成完整实机验证：

- 补丁安装成功；
- 发烧游戏平台恢复游戏下载；
- 游戏完整下载成功；
- 下载完成后成功进入游戏。

## 三、继续保留的修复

- v1.3.3：Release CMD 入口保持 **无 BOM + CRLF**，避免 Windows 7 `cmd.exe` 解析错乱；
- v1.3.2：managed EXE 验证直接读取 PE CLR / COM Descriptor，兼容 PowerShell 2.0 / 旧 CLR；
- v1.3.1：同版本多布局精确识别、自定义 FeverGames / 7-Zip 路径；
- v1.2：已完成端到端验证的 .NET 下载核心。

## 四、已验证前端布局

- `1.18.42.12 / layout A`
- `1.18.42.14 / layout A`
- `1.18.42.14 / layout B`
- `1.18.43.22 / layout A`

安装器仍不会仅根据版本文件夹名称强行套用补丁。只有对应 profile 的 5 个目标位置全部处于已知原始 / 已补丁状态时才会继续；未知或变化布局会安全停止。

## 五、使用方法

完全退出 FeverGames 后运行：

```text
01_一键安装.cmd
```

正常结果应包含：

```text
Frontend patch count: 5/5
downloadIPC.exe = managed Win7 replacement
rollback backup = COMPLETE
RESULT=READY_FOR_WIN7_FEVERGAMES_DOWNLOAD
```
