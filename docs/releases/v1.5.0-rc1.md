# v1.5.0 RC1 — 官方 Go 下载组件 Win7 兼容

**状态：候选测试版，尚未进入正式 Release。** 默认分支和 v1.4.2 正式版保持不变。

## 用户已验证：test2-r4

- Windows 7 SP1 x64 下，FeverGames 1.18.45.8 前端五点修补与官方 Go 1.23.8 下载组件配合成功。
- 游戏完整下载，下载速度与官方相当。
- 暂停与恢复均可立即响应。
- Windows 重启后可正常断点续传。
- FeverGames 平台游戏校验和修复成功。

## RC1 整理内容（新增安装流程，仍须复测）

- 安装入口自动寻找最新完整数字版本目录，支持常见磁盘目录、部分注册表路径、快捷方式及保存位置；仍可手动选择。
- 六份历史已验证的前端 Exact Profile 自动选择，**不按文件夹版本盲目修补**。
- 仅识别两份已实测对应的 Go 1.23.8 原版 SHA-256（签名变体 A/B）。
- 安装器在本地对原始二进制精确修改少量字节，并验证修补结果与已知成品 SHA-256 完全一致；不在安装包中重新分发官方 EXE。
- 两个组件独立保存真实官方原版、支持回滚及状态检查；支持读取此前 test2-r4 备份。
- Windows 7 用户端不依赖 PowerShell、Python、.NET、csc.exe。需要 WSH、ADODB.Stream、MSXML3/6 和 certutil。

## 尚未满足的条件

- 新编写的 RC1 自动目录发现、现场 Go 二进制修补、首次安装及回滚尚需 Win7 实机复测。
- 历史 **Auto Profile v2** 对未知新版前端的结构扫描，尚未移植为纯 Windows Script Host 方案；现阶段只使用 Exact Profiles，未知构建拒绝修改。
- 早期前端构建与 Go A/B 核心的交叉组合尚未实测。
- 旧版 05 C# 独立下载器未并入，以避免重新引入 PowerShell/.NET 依赖。
- 修改官方 EXE 后原数字签名无效，可能受平台附加完整性策略影响。
