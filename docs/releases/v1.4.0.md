# FeverGames Legacy Windows Downloader v1.4.0

v1.4.0 是一次较大的功能更新。

这次新增独立下载器的核心目的，是为 **FeverGames 平台无法安全修补时提供备用方案**。以前项目主要依赖对 `FeverGamesInstaller.exe` 进行精确补丁；如果 FeverGames 更新后二进制布局发生变化，而 Built-in Exact Profile / Auto Profile 又无法可靠识别，为了避免盲目修改，完整补丁会主动停止。

v1.4.0 因此增加了一条不依赖 FeverGames 前端补丁的路径：可以绕开发烧游戏平台前端，直接解析最新版信息并完成受支持的 Manifest / Index / Chunk 下载链。平台仍能安全修补时，依旧建议优先使用 `01_一键安装.cmd` 恢复原生 FeverGames 下载体验；只有在前端暂时无法适配时，再使用独立下载器兜底。

同时，本版本还加入了 **游戏更新检查 / 校验修复** 与 **仅修补 `downloadIPC.exe`** 的独立入口。

## 主要更新

### 1. 新增独立游戏下载器

这个功能首先是为了应对 **FeverGames 新版前端无法继续安全修补** 的情况，而不是单纯为了把官方客户端下载流程再做一遍。

当 `FeverGamesInstaller.exe` 新版布局发生变化、完整补丁无法通过安全验证时，可以改用：

```text
05_独立下载_检查更新与修复.cmd
```

它不依赖 FeverGames 前端补丁，也无需先让 FeverGames 创建官方下载任务；对于当前支持的新版文件分发链，可以直接根据游戏 App ID 完成：

```text
App ID
→ 获取游戏信息
→ 获取最新版本
→ 获取 Content ID
→ 获取 Manifest
→ Index / Chunk 下载
→ AES-CTR 解密
→ Zstd 解压
→ 文件构建
→ MD5 校验
```

同时支持默认 / 自定义安装目录、禁止磁盘根目录、目录确认后返回修改、HDD / SSD 参数与实时进度条。

### 2. 新增游戏更新检查与修复

如果游戏已经由 FeverGames 登记安装，05 会读取当前安装版本并与服务器最新版本比较。

检测到新版本时可直接使用原安装目录增量更新；已经是最新版时也可以执行校验 / 修复，并尽量复用已有正确文件。

### 3. 新增仅修补 downloadIPC.exe

新增：

```text
06_仅修补downloadIPC.cmd
```

这个入口 **不会修改 `FeverGamesInstaller.exe`**，只替换 FeverGames 实际负责新版文件分发任务的 `downloadIPC.exe` 并配置 `libzstd.dll`。

已实机验证：修补后，FeverGames 平台内原本会失败的“游戏修复”功能可以正常完成。

### 4. 完整补丁入口继续保留

原有用户仍然可以继续使用：

```text
01_一键安装.cmd
02_检查状态.cmd
03_恢复官方文件.cmd
04_收集诊断.cmd
```

完整补丁仍是首选方案：只要当前 FeverGames 前端布局能够通过 Exact Profile / Auto Profile 安全识别，就优先恢复平台本身的下载能力。只有当新版平台布局发生变化、无法安全修补时，才建议使用 05 独立下载器作为备用路径。

### 5. Index Tail Recovery

针对部分机器 Index 最后阶段反复卡在约 99% 的问题，v1.4.0 使用：

```text
普通 Index：
HDD 24 workers
SSD 32 workers

最后 64 个 Index：
最多 4 workers
Keep-Alive = false
Timeout = 10 秒
Retry = 3 次
```

该方案已在此前会反复卡在 Index 尾段的 Windows 7 环境中完成实机验证。

### 6. 自动解析最新版 target_version

v1.4.0 已确认可通过 FeverGames 文件分发接口匿名获取最新 build 信息，因此独立下载器不再需要先启动一次官方下载任务。

### 7. 下载完成后自动登记到 FeverGames

独立下载完成后可以写入 FeverGames 当前用户的游戏安装登记，使平台识别现有游戏目录。该流程已经完成实机验证，并成功从 FeverGames 启动游戏。

## 已知限制：Aria2 / 经典下载游戏

并不是所有 FeverGames 游戏都使用当前独立下载器支持的 Manifest / Index / Chunk 下载链。

部分游戏仍可能使用 **Aria2 / 经典下载方式**。对于这类游戏：

- 05 独立下载器暂不支持；
- 请继续使用 FeverGames 平台自身的下载功能；
- 如果平台只是因为 Windows 7 系统检测而阻止下载，可先运行 `01_一键安装.cmd`；
- `06_仅修补downloadIPC.cmd` 主要针对 downloadIPC 下载链，并不是 Aria2 的替代实现。

## 正式版整合修复

正式版打包前还修复了两个完整补丁入口问题：

- 修复完整补丁脚本中 `packageRoot` 未在主作用域初始化，导致 `Join-Path -Path` 收到空值而中止的问题；
- 修复先使用 `06_仅修补downloadIPC.cmd` 后再运行 `01_一键安装.cmd` 时，完整补丁无法识别 `FGWin7_Backup\downloadIPC.exe.original` 原版备份的问题。

两项均已在 Windows 7 + FeverGames 1.18.44.2 实机重新验证。

## 使用入口

```text
01_一键安装.cmd
完整 FeverGames Win7 补丁

02_检查状态.cmd
检查完整补丁当前状态

03_恢复官方文件.cmd
恢复补丁安装前的官方文件

04_收集诊断.cmd
生成问题排查所需的诊断信息

05_独立下载_检查更新与修复.cmd
独立游戏下载 / 检查更新 / 增量更新 / 校验修复

06_仅修补downloadIPC.cmd
只修补 FeverGames 下载组件，不修改 FeverGamesInstaller.exe
```

## 兼容性

当前主要面向 Windows 7 SP1 x64。

已验证 Built-in Exact Profile：

```text
1.18.42.12 / layout A
1.18.42.14 / layout A
1.18.42.14 / layout B
1.18.43.22 / layout A
1.18.44.2 / layout A
```

未知 / 变化布局只有 Auto Profile 5/5 结构与字节验证全部通过才会继续，否则安全停止。
