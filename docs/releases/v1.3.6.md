# FeverGames Legacy Windows Downloader v1.3.6

本版本新增对 FeverGames **1.18.44.2 / layout A** 的正式支持，并修复一处仅影响诊断信息收集的旧 CLR 兼容问题。

## 主要变化

- 新增 `1.18.44.2-A` 精确补丁配置。
- 1.18.44.2-A 已在 Windows 7 SP1 x64 实机完成完整验证：
  - 5/5 前端补丁点成功；
  - managed `downloadIPC.exe` 正常接管；
  - `libzstd.dll 1.5.6` 正常工作；
  - 游戏文件 `3133/3133` 完整下载；
  - 游戏可正常启动并进入世界。
- 修复 `04_收集诊断.cmd` 在 Win7 / CLR 2.0 环境下生成 `decoder_info.txt` 时，`SHA256Managed.Dispose()` 不可用导致 SHA-256 元数据采集失败的问题。
- 下载核心继续使用 v1.3.5 已验证的 **内置 libzstd + 串行下载/重组路径**。
- 不包含 Test2 / Test3 / Test4 的实验并发优化。
