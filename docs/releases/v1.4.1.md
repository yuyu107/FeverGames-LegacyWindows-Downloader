# FeverGames Legacy Windows Downloader v1.4.1｜旧版 GZip 下载链兼容修复

v1.4.1 是 v1.4.0 的兼容性修复版本，主要解决部分旧资源 **Index 可以全部完成，但实际 Chunk 下载中途失败** 的问题。

## 主要更新

### 1. Legacy Index 支持 AES-CTR + GZip

补充旧版 Manifest / Index 分发格式：

- 支持 `index_url` / `pb_size`；
- 支持 AES-CTR + GZip Index 解码；
- 保留新版 `index_url_v2` / AES-CTR + Zstd 路径。

### 2. Chunk 自动识别 Zstd / GZip

此前下载核心在 AES-CTR 解密后默认把 Chunk 强制交给 Zstd。

v1.4.1 改为：

```text
AES-CTR decrypt
→ detect Zstd / GZip
→ decode
→ build file
```

如果仍然遇到未知格式，会在日志中保留解密后 `first16`，方便继续分析新的旧资源格式。

### 3. 05 / 06 两条下载链同步

本次兼容同时进入：

- `05_独立下载_检查更新与修复.cmd` 使用的 `app/core.cs`；
- `06_仅修补downloadIPC.cmd` / FeverGames 平台内下载任务使用的 `app/ipc.cs`。

因此独立下载和平台内 downloadIPC 不会再出现一边能处理、另一边仍失败的情况。

### 4. 《第五人格》实机验证

此前《第五人格》可以完成 **439/439 Index**，随后在实际 Chunk 下载阶段中途停止。

加入 Legacy AES-CTR + GZip Chunk 支持后，已成功完成整游戏下载。
