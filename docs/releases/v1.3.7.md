# FeverGames Legacy Windows Downloader v1.3.7

本版本将最后一轮实机测试中验证可用的 **Index 下载优化、平衡型 Chunk / Build 管线**整理为正式版，并加入实验性的 **Auto Profile** 未知布局识别备用路径。

## 主要变化

- Manifest 先完成解析，再进入 Index 状态，索引总大小可以在阶段开始时直接获得。
- Index 保持 Manifest 原始顺序，避免按最终文件大小排序后把大量小 Index 集中到尾段。
- Index 并发提高到 **HDD 64 / SSD 96**，并同步提高 HTTP 连接上限。
- Index 使用进程内 `AES-CTR -> libzstd -> Protobuf` 路径，减少临时文件 I/O。
- 减少 Index 热路径中的同步日志写入，并优化 AES Key 探测和成功 Key 缓存。
- 主下载正式采用平衡型 Chunk / Build 管线：HDD `8 + 6 + 1`，SSD `12 + 10 + 2`。
- 保留 `libzstd.dll 1.5.6` 进程内 Zstandard 解压。
- Release CMD 继续保持无 BOM + CRLF，兼容 Windows 7 `cmd.exe`。

## 前端兼容

已验证的 Built-in Exact Profile：

- `1.18.42.12 / layout A`
- `1.18.42.14 / layout A`
- `1.18.42.14 / layout B`
- `1.18.43.22 / layout A`
- `1.18.44.2 / layout A`

本版本还包含实验性的 **Auto Profile** 结构识别备用路径，用于遇到未收录的新版本 / 新布局时尝试定位所需补丁点。只有全部目标通过结构与字节校验时才允许继续，否则安全停止。

> 当前没有更新后的 FeverGames 新版本可供实机验证，因此 Auto Profile 尚未经过真正未来新版验证，不应视为对未来版本兼容性的保证。后续出现新版本后，应先实测并在确认后将布局固化为 Built-in Exact Profile。
