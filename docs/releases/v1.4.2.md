# FeverGames Legacy Windows Downloader v1.4.2｜1.18.45.8 适配与 Auto Profile v2

本次正式版在 v1.4.1 基础上更新，重点是新的 FeverGames 前端适配和自动识别稳定性。

### 主要变化

- **FeverGames 1.18.45.8 / layout A**：加入已实机验证可以继续下载的五点补丁配置；该精确配置同时要求完整原版 EXE SHA-256 匹配，避免误改其它构建。
- **Auto Profile v2**：不再将 GateB 后续对象字段固定在 `0x200`，支持受限的字段布局偏移变化（例如新版 `0x210`），同时保留调用目标、条件跳转、可执行 PE 段、唯一候选、五点原始字节以及备份和回滚验证。
- **独立下载器回退基础选择界面**：只需输入数字 App ID。直接回车时使用 **App ID 81：我的世界基岩互通版**，继续检测是否已安装、是否需要更新或修复。
- **GamePicker 暂缓**：不将联网搜索、列表、历史、缓存等实验功能收入正式版；后续可作为独立项目开发。
- **原有功能继续保留**：v1.4.1 的第五人格 Legacy AES-CTR + GZip Index/Chunk 修复、独立下载、游戏更新/修复、Index Tail Recovery、平台内 downloadIPC 修复均保留。

### 注意事项

本版 Auto Profile v2 已在 1.18.45.8 环境测试通过，但不保证任何未来版本都能自动适配；无法唯一识别时会拒绝修改。

正式包：`FGWin7_v1.4.2.zip`，附 SHA-256 校验文件。
