# v1.5.0｜官方 Go 下载核心与 Windows 7 兼容修复

本次更新将发烧游戏平台内的下载核心切换为经过 Windows 7 兼容修补的官方 Go 版 `downloadIPC.exe`，继续保留官方的下载、暂停恢复、断点保存和文件校验逻辑。

此前测试中已完成游戏下载，速度与官方相当；暂停与恢复能够迅速响应，重启系统后可以继续下载，游戏校验与修复也已通过测试。

**适用系统：Windows 7 SP1 x64。正式安装包：`FGWin7_v1.5.0.zip`。**

请下载本 Release 附件中的正式安装包。GitHub 的 **Code → Download ZIP** 是仓库源码，不等同于正式安装包。

## 主要更新

### 使用官方 Go 下载核心

- 修复已验证的官方 Go 1.23.8 下载组件在 Windows 7 上的随机数 API 兼容问题。
- 配合前端五点补丁，解除已适配布局中的系统版本检测阻拦。
- 平台内下载采用官方核心，保留官方 IPC 通信、任务管理和文件构建流程。
- 改善此前替代下载核心的速度和暂停后恢复体验。

### 自动识别与版本适配

- 自动寻找发烧游戏安装位置，并选择最新的完整版本目录。
- 内置前端精确配置：`1.18.42.12-A`、`1.18.42.14-A/B`、`1.18.43.22-A`、`1.18.44.2-A`、`1.18.45.8-A/B`。
- 保留 Auto Profile v2；未知前端布局只有通过唯一候选、指令结构、跳转目标和五处补丁位置等校验后才允许修补。
- 支持已验证的 Go 下载组件 A/B/C 签名变体。其他仅签名或 PE 校验和不同的文件，可通过已知程序主体哈希进行识别。
- **Go 组件重新编译、程序主体变化后的通用结构适配尚未实现。** 无法识别的新构建仍会停止修补，不能保证未来所有版本自动兼容。

### 中文一键安装

- 安装、状态检查、诊断及错误提示采用简体中文。
- 运行 `01_一键安装.cmd` 后自动识别、校验、备份并安装，无需输入 `INSTALL`，也无需先运行状态检查。
- 目标目录及文件可写时直接执行；写入受限时才尝试申请管理员权限。
- 安装结果与错误信息保留在窗口中，便于检查。
- 平台补丁安装无需 PowerShell、Python 或 .NET 编译。

### 保留独立下载器

正式包补回 `05_独立下载_检查更新与修复.cmd`，沿用 v1.4.2 正式版的独立下载实现：

- 输入 App ID，直接回车默认使用 `81`（我的世界基岩互通版）。
- 支持安装目录选择、已有安装检测、更新及校验修复。
- 保留 Zstd，以及 Legacy AES-CTR + GZip Index/Chunk 兼容。

**05 仍使用原有的 PowerShell/C# 独立核心，需要其原有依赖。** 平台内使用的官方 Go 下载核心与 05 独立下载器是两条不同的下载路径。

## 使用方法

1. 完全退出发烧游戏，包括托盘中的客户端及 `downloadIPC.exe`。
2. 将 `FGWin7_v1.5.0.zip` 完整解压到当前用户可写的文件夹。
3. 运行 `01_一键安装.cmd`。只有需要提权时才会申请系统管理员权限。
4. 安装成功后，正常打开发烧游戏平台下载、更新或修复游戏。

已成功安装 RC5 的用户，无需为了正式版先恢复或重装。运行正式包的安装入口时，会检查当前已修补状态。

自动识别不到安装目录时，可将版本目录作为 CMD 的第一个参数，例如：

```bat
"01_一键安装.cmd" "D:\Program Files\FeverGames\1.18.45.8"
```

## 包内入口

| 入口 | 用途 |
| --- | --- |
| `00_Package_SelfCheck.cmd` | 安装包完整性自检，可选运行 |
| `01_一键安装.cmd` | 自动识别并安装完整补丁 |
| `02_检查状态.cmd` | 只读检查前端及下载组件状态 |
| `03_恢复官方文件.cmd` | 校验备份并恢复官方文件，需输入 `RESTORE` |
| `04_收集诊断.cmd` | 保存路径、文件哈希及备份存在状态 |
| `05_独立下载_检查更新与修复.cmd` | 独立下载安装、更新及校验修复 |
| `06_仅修补downloadIPC.cmd` | 仅修补官方 Go 下载组件，不修改前端 |

## 运行依赖

| 功能 | 依赖 |
| --- | --- |
| 平台补丁及检查、恢复、诊断 | Windows Script Host、MSXML3/6、ADODB.Stream、`certutil.exe` |
| 05 独立下载器 | Windows PowerShell、兼容的 .NET C# 编译器及包内 `libzstd.dll` |

05 首次运行时会在 `app` 目录编译独立下载核心，请保留完整目录结构，并将压缩包解压到可写位置。

## 备份与恢复

- 安装前会校验原始文件、补丁字节及生成结果，并保存原版备份。
- v1.5.0 备份目录为对应客户端版本目录下的 `.FGWin7_150_Backup`。
- 支持从 test2 及旧版 v1.2/v1.3/v1.4 的已知备份位置查找通过校验的原始文件。
- 需要恢复时，退出平台后运行 `03_恢复官方文件.cmd`。恢复前会核对当前文件及备份哈希，避免覆盖安装后已被更新的文件。
- 请保留原版备份。修改 EXE 后，其原有数字签名会失效；本包不包含网易官方完整 EXE。

## 验证情况与已知限制

- Windows 7 虚拟机：官方 Go 核心已通过完整下载、暂停恢复、系统重启后续传及游戏校验修复测试。
- Windows 7 实体机：RC5 已成功修补并完成游戏下载；正式版沿用相同的前端/Go 补丁配置与核心修补算法。
- 正式包已完成离线字节、哈希及压缩包完整性检查；本次新增的按需提权流程及最终组合尚未完成 Win7 实机回归。
- 05 的核心源码、脚本与 `libzstd.dll` 原样取自 v1.4.2 正式发布包。
- 05 不保证支持 Aria2/经典分发游戏，这类游戏请优先通过发烧游戏平台下载。
- 本项目修复的是平台下载兼容性，不保证下载后的每款游戏本体都能在 Windows 7 上运行。
