# 反馈指南

请使用 [Issue 选择页面](https://github.com/yuyu107/FeverGames-LegacyWindows-Downloader/issues/new/choose)，按问题选择模板：

| 类型 | 适用情况 |
| --- | --- |
| 故障反馈 | 安装、提权、检查、恢复、下载、续传、更新或修复异常 |
| 新版本/布局适配 | 客户端更新后提示未知前端布局、未知 Go 构建或哈希无法识别 |
| 功能建议 | 交互、诊断、下载功能或兼容策略的改进建议 |

## 最有帮助的信息

1. 补丁版本、下载的 ZIP 文件名，以及 Windows 版本/位数；是实体机还是虚拟机。
2. 发烧游戏版本目录，例如 `D:\Program Files\FeverGames\1.18.45.8`；同版本目录也可能有不同构建。
3. 使用哪个编号入口；是平台内下载还是 05 独立下载。
4. 具体操作、完整错误及退出码、预期结果与实际结果。
5. 游戏名称/App ID、出错阶段和能否重复；续传问题注明是否重启过客户端或系统。

如果无法提供某项，请写“不清楚”，不需要为填表重新安装系统或删除备份。

## 状态与诊断

- `02_检查状态.cmd`：复制完整输出，包含前端匹配情况及下载组件哈希。
- `04_收集诊断.cmd`：按窗口提示找到诊断文件。v1.5.0 默认写入 `%LOCALAPPDATA%\FeverGamesLegacyDownloader\FGWin7_150_diagnostic.txt`。
- 安装器错误：保留从标题到退出码的完整输出；若涉及提权，保留提权前后两个窗口的输出。
- 新版本适配：优先提供两个 EXE 的 SHA-256、前端五点识别结果及官方文件来源/恢复情况。先不要删除备份、跳过校验或反复重装。

诊断摘要不包含完整下载日志，不能只凭摘要判断网络或 Chunk 阶段故障。需要进一步信息时会在 Issue 中说明。

## 公开前检查

Issue 和附件是公开的。请移除账号 Token、Cookie、AES key、PRIVATE Manifest 响应、设备标识及带临时鉴权的链接；截图可遮盖用户名等个人信息。不要直接公开上传整个安装目录、存档或完整官方 EXE。

可以先提交文字输出和脱敏诊断；如确需二进制样本，先讨论合适的提交方式。

## 依赖与范围

01/02/03/04/06 不需要 PowerShell/.NET 编译；05 仍需要这些组件。反馈“依赖缺失”时请注明入口。

当前目标为 Win7 SP1 x64。Go 主体改变的新构建尚不能通用自动适配；游戏自身无法启动，也不一定属于平台下载故障。请说明故障发生在下载前、下载中还是完成后启动游戏时。
