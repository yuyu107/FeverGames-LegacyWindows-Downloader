发烧游戏旧版 Windows 下载器 v1.3.7

v1.3.7 的主要变化
------------------
1. 将实机测试中验证可用的 Index 下载优化与平衡型 Chunk / Build 管线整理为正式版。
2. Manifest 会先完成解析，再进入 Index 状态，因此索引总大小可以在阶段开始时直接获得。
3. Index 保持 Manifest 原始顺序，避免把大量小 Index 集中到下载尾段。
4. Index 并发提高到 HDD 64 / SSD 96，并减少临时文件 I/O、热路径同步日志和重复 AES Key 探测。
5. 主下载管线采用 HDD 8 + 6 + 1 / SSD 12 + 10 + 2。
6. 新增实验性的 Auto Profile，用于未知前端布局的结构识别备用路径。
7. 继续使用内置 libzstd.dll 1.5.6，不需要另外安装 7-Zip。

关于 Auto Profile
-----------------
已知版本仍优先使用 Built-in Exact Profile。
只有未知布局才会尝试 Auto Profile，而且必须全部目标通过结构与字节验证；
任一目标不确定或不满足条件都会安全停止。

当前没有真正更新后的 FeverGames 新版本可供实机验证，因此 Auto Profile 暂时不能视为未来版本兼容保证。
后续出现新版本时应先测试；确认成功后再把对应布局固化为 Built-in Exact Profile。

使用
----
1. 先完整解压整个 ZIP，不要直接在压缩包中双击 CMD。
2. 完全退出发烧游戏。
3. 运行 01_一键安装.cmd。
4. 可用 02_检查状态.cmd 检查结果。

正常状态应包括：
Frontend patch count: 5/5
downloadIPC.exe = managed Win7 replacement
decoder = libzstd.dll ... (in-process)
rollback backup = COMPLETE
RESULT=READY_FOR_WIN7_FEVERGAMES_DOWNLOAD

恢复
----
运行 03_恢复官方文件.cmd。
如果 libzstd.dll 是本工具复制的且安装后未被修改，会根据记录的 SHA-256 一并删除。

诊断
----
运行 04_收集诊断.cmd。

诊断目录：
FeverGames_v1.3.7_Diagnostic_Result

关于性能
--------
v1.3.7 正式采用经过测试后保留的并发方案。
Index 阶段会优先减少 HTTP 往返和小文件固定开销，主下载阶段则采用平衡型 Chunk / Build 管线。
不同游戏、CDN、磁盘和网络环境差异较大，因此实际速度仍可能变化；Win7 替代 downloader 不保证达到 Win10 / Win11 官方 downloader 的同等速度。

安全机制
--------
项目不会只根据版本文件夹名称盲目套用旧偏移。
Built-in Exact Profile 和 Auto Profile 都必须完成全部目标验证；验证失败时会安全停止。

Release CMD 入口保持无 BOM + CRLF，以兼容 Windows 7 cmd.exe。
