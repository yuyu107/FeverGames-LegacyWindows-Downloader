FeverGames Legacy Windows Downloader v1.3.4
============================================================

用途
----
用于恢复发烧游戏（FeverGames）新版下载后端在 Windows 7 SP1 x64 上的运行能力。
本工具解决的是发烧游戏“下载流程兼容”，不是保证所有下载下来的游戏本体都能在 Windows 7 上运行。

v1.3.4 主要更新
----------------
1. 新增 FeverGames 1.18.43.22 / layout A 精确字节支持。
2. Windows 7 实机已完成完整验证：补丁安装成功、游戏完整下载成功，并在下载完成后成功进入游戏。
3. 继续要求 5 个目标位置全部精确匹配；未知或发生变化的布局会安全停止，不会仅按版本文件夹名称强行套用旧补丁。
4. 保留 v1.3.3 的 Release CMD 无 BOM + CRLF 修复。
5. 保留 v1.3.2 的 PowerShell 2.0 / 旧 CLR 托管 EXE 验证修复。
6. 下载核心继续沿用已完成端到端验证的 v1.2 .NET 实现。

已验证前端布局：
- 1.18.42.12 / layout A
- 1.18.42.14 / layout A
- 1.18.42.14 / layout B
- 1.18.43.22 / layout A

Release 包运行 01_一键安装.cmd；源码仓库运行 01_Zero_Start_One_Click_Install.cmd。
正常状态应包含 Frontend patch count: 5/5、downloadIPC.exe = managed Win7 replacement、rollback backup = COMPLETE、RESULT=READY_FOR_WIN7_FEVERGAMES_DOWNLOAD。
