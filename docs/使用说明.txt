FeverGames Legacy Windows Downloader v1.5.0 正式版
============================================================
目标系统：Windows 7 SP1 x64。

【快速使用】
完全退出发烧游戏及 downloadIPC.exe，完整解压本包，运行 01_一键安装.cmd。
自动寻找最新完整版本，识别、备份并修补前端和官方 Go 下载组件，无需输入 INSTALL。
目录及文件可写时直接执行，只有写入受限时才尝试申请系统管理员权限。
安装成功后照常在发烧游戏平台下载、暂停恢复、更新及修复游戏。
已经安装成功的 RC5，无需为了正式版先恢复或重装；重复安装会检查当前状态。
若文件被占用，也可能出现写入受限提示，请先完全退出平台。

【中文编号入口】
00_Package_SelfCheck.cmd          安装包自检（可选）
01_一键安装.cmd                  自动识别并安装完整补丁
02_检查状态.cmd                  只读检查前端及下载组件状态
03_恢复官方文件.cmd              恢复备份中的官方文件（输入 RESTORE）
04_收集诊断.cmd                  保存路径、哈希和备份存在状态
05_独立下载_检查更新与修复.cmd    独立下载器：App ID、安装、更新及校验修复
06_仅修补downloadIPC.cmd         仅修补官方 Go 下载组件，无需输入 GOONLY
自动识别失败时，可向入口 CMD 传入发烧游戏版本目录作为第一个参数。

【平台补丁与独立下载器】
01/02/03/04/06 使用 Windows Script Host、MSXML3/6、ADODB.Stream 和 certutil。
这些平台补丁入口无需 PowerShell、Python 或 .NET 编译。
05 完整保留 v1.4.2 正式版独立下载器的原有实现及依赖，需要 PowerShell、.NET C# 编译器和包内 libzstd.dll。
05 默认 App ID 81（我的世界基岩互通版），支持自选目录、已有安装检测、更新和校验修复，保留 Legacy AES-CTR/GZip 与 Zstd 支持。
05 仍使用 C# 独立核心，没有改用官方 Go 组件。部分 Aria2/经典下载游戏需在平台内下载。
首次运行 05 会由原有脚本在 app 目录编译下载核心，因此请解压到当前用户可写的文件夹。

【自动适配】
前端精确配置：1.18.42.12-A、1.18.42.14-A/B、1.18.43.22-A、1.18.44.2-A、1.18.45.8-A/B。
未知前端通过 Auto Profile v2 结构规则验证，要求五点位置、唯一候选、可执行节和跳转目标等全部通过。
官方 Go 组件支持 A/B/C 三种精确签名样本；其他签名样本只有已知程序主体哈希一致时才允许修补。
新编译、程序主体改变的 Go 构建尚不支持通用结构适配，会停止并请求进一步分析。
不能识别的文件不会跳过验证强行覆盖；未来客户端更新仍可能需要适配。

【备份与恢复】
本机原版备份保存在对应版本目录下 .FGWin7_150_Backup，包含两份原始 EXE 及完整文件哈希。
兼容 test2、旧版 v1.2/v1.3/v1.4 的已知原版备份位置。
修改 EXE 后原有数字签名会失效。本包不分发网易官方完整 EXE。
恢复会核对当前文件及备份；已被其他版本更新的文件不会被直接覆盖。
恢复成功后会保留备份；再次安装时可直接识别并复用通过校验的原版备份。

【验证记录与限制】
用户已在 Win7 虚拟机验证官方 Go 核心的完整下载、与官方相当的速度、迅速暂停恢复、重启续传和校验修复。
用户已在 Win7 实体机验证 RC5 修补并完成游戏下载。正式版沿用同一套前端/Go 补丁配置及核心修补算法。
正式版补回的 05 文件逐字节取自 v1.4.2 正式发布包；不将其描述为新的 Go 独立下载器。
本轮完成离线字节、哈希、目录结构和 ZIP 校验；按需提权流程及正式包组合尚未在 Win7 重新实机回归。
本工具不保证所有下载后的游戏本体都能在 Win7 运行。
