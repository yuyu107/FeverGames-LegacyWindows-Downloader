FeverGames Legacy Windows Downloader
Version: 1.3.5
Release status: Stable
Verified FeverGames frontend builds/layouts: 1.18.42.12 / layout A, 1.18.42.14 / layout A, 1.18.42.14 / layout B, 1.18.43.22 / layout A

v1.3.5:
- Replaced the external 7-Zip / zstd.exe Zstandard path with in-process libzstd.dll 1.5.6 via P/Invoke.
- Windows 7 users no longer need to install 7-Zip when using the Release ZIP.
- Standalone libzstd streaming decode passed on Windows 7 SP1 x64 under CLR 2.0.
- A real FeverGames download completed without using 7-Zip.
- Status and diagnostics now report the libzstd backend; restore removes the patch-supplied DLL only when its recorded SHA-256 is unchanged.
- Experimental file/chunk concurrency from Test2/Test3/Test4 is intentionally not included in the stable build.

v1.3.4:
- Added exact-byte support for FeverGames 1.18.43.22 / layout A.
- Windows 7 real-machine verification completed: patch install, full game download and game launch succeeded.
- Unknown or changed layouts are still rejected unless all 5 exact target bytes match.

v1.3.3 packaging fix retained:
- Release CMD wrappers use BOM-less ASCII with CRLF line endings for Windows 7 cmd.exe compatibility.

v1.3.2 compatibility fix retained:
- Managed downloadIPC validation is CLR-independent and PowerShell 2.0 safe.
