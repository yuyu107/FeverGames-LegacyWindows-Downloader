FeverGames Legacy Windows Downloader v1.3.1

适用系统：Windows 7 SP1 x64

【最简单的使用方法】
1. 正常安装或更新发烧游戏（FeverGames），然后完全退出平台。
2. 确保电脑中有支持 .zst 的 7-Zip；也可以将可在 Windows 7 使用的 zstd.exe 放到 tools\zstd.exe。
3. 如果使用 Releases 中的 v1.3.1 ZIP，双击：01_一键安装.cmd
   如果直接下载 GitHub 源码，双击：01_Zero_Start_One_Click_Install.cmd
4. 安装结束后会自动进行状态检查。
5. 如需手动检查状态，运行 02_检查状态.cmd（源码中为 02_Check_Status.cmd）。
6. 如需恢复官方文件，运行 03_恢复官方文件.cmd（源码中为 03_Restore_Official_Original.cmd）。
7. 遇到问题可运行 04_收集诊断.cmd（源码中为 04_Collect_Diagnostics.cmd）。

【v1.3.1 新增】
- 新增 FeverGames 1.18.42.14 / layout B 精确补丁配置。
- 同一个 1.18.42.14 版本号出现不同 FeverGamesInstaller.exe 布局时，会根据 5 个目标位置的真实字节完整匹配，不会只看版本号盲目修补。
- 支持 FeverGames 安装在自定义目录；自动查找失败时，可直接拖入 FeverGames 根目录、数字版本目录或 FeverGamesInstaller.exe。
- 支持 7-Zip 安装在自定义目录。
- 修复 Windows 7 下 UAC 一键安装等待与 PowerShell 2.0 保存自定义路径的问题。
